美元体系的优势与约束

01 / 融资优势

为什么资金愿意回流？

美国企业和政府可以用本币借款，全球买家则获得流动性较好的美元资产。广泛的买家基础有助于降低融资成本，长期优势取决于市场深度、购买力和制度信任。

02 / 财政约束

贸易逆差和财政赤字怎么区分？

贸易逆差看进出口差额，财政赤字看政府收支差额。美元也能通过跨境信贷流通，联邦债务则主要随财政赤字和借款变化。截至 2025 财年末，美国联邦总债务约 37.5 万亿美元。按美国国会预算办公室口径，该财年净利息约 9,700 亿美元，高于国防总支出约 8,910 亿美元。

03 / 储备与结算

如何观察美元地位的变化？

央行增持黄金可以分散储备，一些贸易伙伴也可以选择本币结算。要判断美元的地位是否变化，可以分别跟踪外汇储备构成、贸易计价与结算、跨境融资币种。它们变化的速度可能不同。

BEYOND THE PRICE / 本质与思考

07 读懂联系，也读懂变化的原因。

五种资产，是观察全球经济权力结构的一扇窗。

黄金、美元、美股、美债与石油，连接着货币制度、国家信用、企业盈利、能源供需与政策选择。它们的涨跌，也折射出人们面对收益、不确定性、贪婪与恐惧时的反应。

把历史与机制放在一起，追问三件事：什么冲击先发生？它通过哪条路径传导？什么条件会让关系反转？这样的提问，比记住一组固定的涨跌搭档更有用。

原理、来源与推演假设

这里展示什么？

这是一个帮助理解传导机制的互动教学页，没有接入实时价格，也没有使用历史样本计算相关系数。情景结论是依据下列原理设计的示意推演，所有权重由本页设定，未经统计拟合。

黄金以美元金价为视角；美元指相对一篮子主要货币的强弱；美股指大盘整体；美债指固定息票中长期美国国债的价格方向，或对应到期收益率的方向；石油指国际原油美元价格。不是具体证券或基金的报价。

  2. 芝加哥联储 · 什么驱动金价？ ↗

  3. 圣路易斯联储 · 债券价格与利率 ↗

推演方式与边界

六项输入是相对基准的假设变化：R 实际利率预期、G 增长预期、I 通胀预期、V 避险需求、S 原油供给收紧、L 现金紧缺。预设把多项变化组合起来；自定义时，各项输入互相独立，不会自动形成经济反馈。

双击资产会进入“手动方向推演”：第一次设为偏弱，再次双击设为偏强。其他资产仅按当前情景下与起点的直接关系联动：双剑反向、握手同向、下棋显示“关系不定”。此时不使用下列加权分值，也不显示强度刻度；不继续沿其他资产递推。切换情景、拖动宏观变量或点击“恢复情景推演”可退出。

美元示意分值 D = 0.9R + 0.25G + 0.7V + 1.1L；名义收益率分值 Y = 0.9R + 0.65I + 0.35G − 0.8V + 1.4L。美元的利率项假设其他经济体利率不变；避险项假设美国资产仍受信任，未建模美国特有的信用冲击。

黄金 = −R − 0.4D + 0.8I + 0.9V − 1.7L

美股 = G − 0.8R − 0.6I − 0.9V − 0.8L − 0.35S

美债价格 = −Y；美债收益率 = Y

石油 = 1.1G + 0.2I − 0.3D + 1.2S − 0.5V − 0.6L

分值绝对值低于 0.45 显示“多空交织”；低于 1.4 显示“偏强 / 偏弱”；否则显示“上行 / 下行压力较强”。这些分档仅便于教学展示，不代表价格幅度、概率或置信度。

未考虑期限溢价、央行购金、OPEC具体政策、公司行业差异、仓位、估值起点和政策反馈；输入也不是对未来的判断。关系网络展示的是常见条件下的机制，不是由两条示意分值计算的相关性。

怎么看才有用？

先选情景，再点资产或两两关系，看清“什么驱动 → 如何传导 → 何时失效”。重点关注变化背后的原因，以及是否已被市场提前计价。
